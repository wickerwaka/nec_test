two writes carry **different values and the order decides**.  At the head of the
chain the row wins; on the `D` pin the data edge wins.  **Not equivalent, and
the falsifier is right.**

## §2 THE REFINED FORM — **THE GATE IS `row_blocked`, AND THE OTHER CASE IS PROVABLY DEAD**

```
  wire        rd_edge_psw_take = eu_rd_edge && (st == S_ROW) && e_f &&
                                 (e_s1 == 5'd6) && (e_d1 == 5'd15) &&
                                 row_blocked;             // <- THE NEW TERM
  wire [15:0] rd_edge_psw      = (eu_rd_edge_d & PSW_WRITABLE) | PSW_FORCED;

  psw <= (srst && !ss_we)              ? psw_r
       : (rd_edge_psw_take && !ss_we)  ? rd_edge_psw
       :                                 psw_n;
```

and block (a)'s write is deleted, as before.  **`row_blocked` is REGISTER-ONLY**
(`st`, `e_f`, and `f_wait`, whose inputs are `nr_wait` — registers plus the
register-derived `eu_rd_done_n` — and `opr_free_now`, a register), so the new
term costs the cone NOTHING: `rd_edge_psw_take` is still `ready` AND registers.

**THE EXACTNESS ARGUMENT, IN TWO CASES THAT PARTITION THE CLOCK.**

* **`row_blocked` HOLDS.**  `S_ROW`'s `chain == 0` arm sets `stop` and assigns
  nothing, positions 1-11 are skipped, so `psw_n` reaches the commit equal to
  its preload `psw` — PROVIDED `poste` and `iend_owed` are not owed, since those
  two blocks run between the old write site and the chain and read-modify-write
  `psw_n`.  **That proviso is FALSIFIER (A) below.**
* **`row_blocked` DOES NOT HOLD.**  The row's acts run: this row is a pure
  register transfer (`row_bus` false, so `row_pre_pair`/`row_pre_wait`/
  `row_slot_wait` are all false; `e_s1 == 6`, not 7, so `row_need_q` is false),
  hence `row_acts_ok` and the step performs `dest1 = FLAGS`, **overwriting
  `psw_n` in its entirety** with `s1_now = opr_live`.  Anything block (a) or
  `poste` put there is DEAD.  So deleting the old write changes nothing here.
  **That is FALSIFIER (B) below.**
