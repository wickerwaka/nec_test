 ⚠ EVERY RUNG IS RESTRICTED TO divclk -> divclk.  Quartus's own Fmax
   Summary note says FMAX is computed ONLY for paths whose source and
   destination are driven by the SAME clock, so a cross-domain path
   (the JTAG hub, the HPS bridge) is not a divclk ceiling and must not
   be quoted as one.  A first run of this script without the filter
   returned the sld_jtag_hub at rung 2; that hit is EXCLUDED here for
   that reason, and this note is why.
