## 1.2 THE LAW, AND IT IS ONE PREDICATE

`wr_cs1` (`v30u_eu.sv:1471`) is the row's **INTENT** to write CS.  A row that
stalls holds that intent for every clock of the stall, and `flush_cs`
(`= cs_now = wr_cs1 ? s1_now : sreg[CS]`) during the stall is **not** the value
that will be written — in `fz2e/533028` it is the instruction's displacement
`7664` against the `ccac` finally written.  The chip writes the register ONCE
and builds anything committed before that from the value the register HOLDS:
wave-3 measured `flush_cs_old` reproducing the chip's fetch **exactly on all
four seats**.

The EU already has the predicate: **`row_acts_ok`** — `(st == S_ROW) &&
!row_blocked && (rowq >= row_qn) && !row_pre_wait` — the rail on which the
row's acts are published, and **the rail `q_flush` itself is qualified by**
(`v30u_eu.sv:2005`).  The redirect and the CS it redirects to are published by
the same row on the same clock, or they are not one act.

    assign flush_cs    = (wr_cs1 && row_acts_ok) ? s1_now : sreg[SR_CS];
    assign flush_cs_we =  wr_cs1 && row_acts_ok;

**No flop, no state, no opcode named, no table.**  It closes the BIU's own
booked remainder at both sites the comment names (`cmt_cs_live` and
`fetch_lin`), because both read `flush_cs` / `flush_cs_we`.

## 2.2 THE LAW, AND IT IS ONE PREDICATE

Silicon announces the ghost read's space from the decode standing at the
cycle's **OWN T1** — the successor opcode, at pop+0 — matched against the
cycle's direction.  The ucore publishes `eu_bs` from `acc_io`, which is
`row_io` = `(e_sr == IO) && (xop == F || xop == 6)` — a **micro-row** field,
which for the ghost is the 8F's own row and is memory.  Wave-3 measured
`eu_bs` first reading `IOR` at **pop+2** in every seat.

The **only pop+0 carrier is `q_byte`**, and the die's own I/O class is already
written in this file: `row_io`'s second half is exactly `pla3_xop ∈ {F, 6}`.
So the space bit gets the same class, evaluated one clock earlier, on the byte
being popped, qualified by direction:

    wire [13:0] ghost_t1_pla   = pla3_native(q_byte);
    wire        ghost_t1_io    = (pla3_xop(ghost_t1_pla) == 4'hF) ||
                                 (pla3_xop(ghost_t1_pla) == 4'h6);
    wire        ghost_space_io = ghost_read_stale_alu && ghost_t1_io &&
                                 !q_byte[1];      // the opcode's direction bit

and `eu_bs`'s read arm becomes `(acc_io || ghost_space_io) ? BS_IOR : BS_MEMR`.

**`!q_byte[1]` IS THE CONTROL THE BRIEF NAMES, AND IT IS SATISFIED BY
CONSTRUCTION.**  `6F`/OUTM has the identical `xop == 6` and differs from `6D`
only in bit 1; silicon says MEMR there.  Bit 1 is the 8086/V30 encoding's own
direction bit and separates `E4 E5 EC ED 6C 6D` (IN, bit1 = 0) from
`E6 E7 EE EF 6E 6F` (OUT, bit1 = 1) with no per-opcode term.

## 2.3 TWO THINGS THIS PACKAGE DOES **NOT** DO, REGISTERED IN ADVANCE

1. **THE ADDRESS DOES NOT MOVE.**  Routing this through `acc_io` would also
   strip the segment from `acc_phys_base`, and **silicon does not**: on three of
   the four seats (`fz2c/410028`, `fz2e/527055`, `fz2e/528030`) the chip's
   ghost T1 address **already AGREES with the core's** (`4070e`, `f79b0`,
   `fd93c`) while the status disagrees.  The space rail reaches the **status

   `eu_bs` alone, and `acc_io`, `eu_seg`, `eu_addr` are untouched.  **This is
   the measurement that chose the site, and it is stated before the edit.**
2. **`fz2e/520066` CARRIES AN ADDRESS DIVERGENCE AS WELL** (chip `35a3b` vs

   cone**.  It is registered here as **NOT EXPECTED TO CLOSE** on this package.

## 2.4 THE OVER-FIRE, NAMED BEFORE IT IS MEASURED

`pla3_xop == 4'hF` also selects **`F0` (LOCK)** and `== 4'h6` also selects
**`F9` (STC)**; both have bit 1 clear, so both would announce `IOR` on a ghost
whose successor is one of them.  The ordinary path excludes them with the
micro-row's `e_sr`, which **does not exist at pop+0** — there is no ROM row yet.
Taking the PLA class unqualified is therefore the SIMPLE reading (the die's own
class, one clock before the ROM can qualify it) and it makes a **prediction**,
not a fit.  It is registered as a falsifier (§2.6), and bar **B-3** (0 LOST) is
where it would be caught.  **Adding an `F0`/`F9` exclusion would be fitting and
is deliberately not done.**

# 3. PACKAGE C — P3-HLT-split

## 3.1 THE BOOKING SPLITS INTO TWO MECHANISMS, AND THIS IS SAID BEFORE THE EDIT

The brief names *"family C2/M4, 3 seats — `sti; hlt` with the pin already high;
core's first acknowledge two clocks early"* and prescribes *"separate
`halt_pending` from `halted`"*.  Read against the F16 atlas those are **two
different populations**, and the prescribed fix reaches only one of them:

* **C-α — the PREFETCH-SUSPEND half, family `B2`, 2 seats**
  (`fz2c/406073` @1574, `fz2e/518044` @2608).  A `HLT` retires into a `PSW.TF`
  trap.  `eu_halt` carries `!brk_seen` (P2's `L-B`), so **neither** the display
  **nor** the suspend is taken, and the ucore issues one more prefetch the chip
  does not (5 diverging rows, one bus cycle, then both legs read vector 1 at the
  identical row).  Silicon: *the `HLT` suspends the prefetcher; the trap
  cancels the display*.  **This is exactly what the port split makes
  representable, and it is the half this package lands.**
* **C-β — the PARK-COST half, family `C2`, 3 seats**
  (`fz2c/404071` @244, `fz2e/514044` @235, `fz2e/516001` @584).  `sti; hlt`
  with the INT pin already high; no trap is involved and `brk_seen` is clear,
  so `eu_halt` and the new suspend port are IDENTICAL on these seats and the
  split cannot move them.  The chip spends **two idle clocks** before its first
  `INTA` T1 even though the display is cancelled by F54's law; the ucore spends
  none.  **This is a WAKE/PARK-COST question, not a display-vs-suspend one, and
  it is BOOKED, NOT LANDED** (§3.5).

**Registered consequence: package C predicts the 2 `B2` seats and predicts
NOTHING for the 3 `C2` seats.**  Their non-movement is a registered NULL, not a
miss.

## 3.2 THE LAW

`eu_halt` is one port and the BIU applies it in two places at two ends of the
edge — `halt_pending` (the DISPLAY, `v30u_biu.sv:1608`) and `halted` (the
PREFETCH SUSPEND, `v30u_biu.sv:2145`).  The EU's `!brk_seen` term belongs to
the display only.  So:

* `v30u_eu.sv` gains **`output eu_halt_susp`** = `eu_halt`'s expression
  **without** `!brk_seen`;
* `v30u_biu.sv` gains the matching **`input eu_halt_susp`** and line 2145 reads
  it instead of `eu_halt`.  Line 1608 (`halt_pending`) is untouched.

**One wire across the port, no flop, no state, no opcode named.**
`eu_unhalt` is untouched: the wake still clears both.

## 3.5 WHAT IS BOOKED, NOT LANDED

**C-β, the park cost when the display is cancelled.**  On `sti; hlt` with the
pin already high the part still spends two clocks before its first `INTA` T1,
with no `HALT` status cycle on the bus.  The ucore's `hlt_wake_int` fires on the
first `S_HALTED` clock, so a cancelled display costs it nothing.  Owner:
`v30u_eu.sv`'s `S_HALTED` / `hlt_wake_int` geometry.
*Falsifier*: a capture in which `sti; hlt` with the pin high delivers `INTA`
with **no** idle clocks between the `HLT` boundary and the acknowledge.
**No code is written for it in this wave**, because the three seats carry 905 /
1,261 / 1,154 diverging rows and a two-clock hypothesis fitted on them, on the
same population that would score it, is what §64.1 forbids.
