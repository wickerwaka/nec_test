## §2 WHERE THE CONE IS, STRUCTURALLY — **ONE TERM, AND IT IS NOT WHERE THE FRAGILITY WAS ASSUMED TO BE**

`READY` enters `v30u_biu`'s next-state function in exactly THREE places, and
they are enumerable by reading:

1. `ready_prev = ready` (`v30u_biu.sv:1627`) — straight to a flop.
2. `rd_data_edge` (`:477`) — registers `AND ready`, published as `eu_rd_edge`.
3. `case (ts)`'s `TS_T3`/`TS_TW` arms (`:1443-1444`) — the READY sample itself.

From (3), the post-advance `ts` is read exactly once more, by M22's
announcement-expiry test `(!run || (ts == TS_T4))` (`:1541`), and what that
reaches on the EU's side is **`slot_busy` → `eu_slot_busy_n`** and nothing else:
`q_ripe_lead_n`, `eu_rd_done_n`, `eu_wr_done_n`, `eu_rdata_n` and
`eu_rd_edge_d` are all functions of REGISTERS ONLY (`done_fire` is `done_ctr`,
the landing quantities are keyed to the *register* `ts == TS_T4`).

`eu_slot_busy_n` is consumed in ONE place, `v30u_eu_step.svh:387`, inside
`S_PRERD`'s `chain == 0` arm — and **every branch of that arm sets
`stop = 1'b1`**, so it decides `row_posted_n` and `rd_pending_n` and does *not*
decide whether the chain continues.  That is the 19–20 level path the retention
netlist measures, ending at `row_posted`.  It closes with +11.4 ns and is not
the problem.

**So by elimination the 62-level cone is `eu_rd_edge`, and it has exactly one
consumer** (`v30u_eu.sv:2303`, block (a), before the twelve-position chain):

```
    if (eu_rd_edge && (st_n == S_ROW) && e_f &&
        (e_s1 == 5'd6) && (e_d1 == 5'd15))
        psw_n = (eu_rd_edge_d & PSW_WRITABLE) | PSW_FORCED;
```

This is F51-era `interrupt_model.md`'s rule — *"POP PSW consumes the popped
image at its read's data edge"* — and it is correct and stays.  What is wrong is
only **WHERE** it is applied: it seeds `psw_n` at the HEAD of a twelve-position
unrolled chain, so one AND gate off `READY` selects the input of the deepest
combinational structure in the core.  Both measured endpoints — §70.3's
`wb_kind[1]` and this sitting's `opc_base[3]` — are chain outputs.

## §3 THE STRUCTURAL PASS — **ONE MUX, MOVED FROM THE HEAD OF THE CHAIN TO THE REGISTER'S OWN `D` PIN**

The G6 precedent (§52) is binding: a structural pass changes HOW logic is
expressed, never WHAT a clocked step computes.

```
  wire        rd_edge_psw_take = eu_rd_edge && (st == S_ROW) && e_f &&
                                 (e_s1 == 5'd6) && (e_d1 == 5'd15);
  wire [15:0] rd_edge_psw      = (eu_rd_edge_d & PSW_WRITABLE) | PSW_FORCED;

  psw <= (srst && !ss_we)              ? psw_r
       : (rd_edge_psw_take && !ss_we)  ? rd_edge_psw
       :                                 psw_n;
```

and the block-(a) write is DELETED.  Nothing else moves: `ie_now` is frozen
*before* the old write and keeps reading the un-overridden `psw_n`, exactly as
it does today (`v30u_eu.sv:2241`, and the comment there says why).

**WHY IT IS EXACT, and it is an ARGUMENT and not only a re-run.**  The two forms
differ only if, on a clock where `rd_edge_psw_take` holds, something between
block (a)'s write and the commit reads or writes `psw_n`.  There are three such
things — `poste`, `iend_owed`, and the chain — and on that clock:

* the row is `OPR -> FLAGS` with the `F` interlock (`e_s1 == 6`, `e_d1 == 15`,
  `e_f`), so `row_reads_opr` holds and `f_wait = nr_wait || !opr_free_now`;
* the read whose data edge this IS has not completed — `done_ctr` is armed at
  that cycle's T4, one clock later, so `eu_rd_done_n` is low and
  `rd_done_cnt` has not been incremented for it;
* therefore `nr_wait` holds, therefore `row_blocked`, therefore `S_ROW`'s
  `chain == 0` arm sets `stop` and assigns NOTHING, and positions 1-11 are
  skipped;
* so `psw_n` arrives at the commit equal to its preload `psw`, and
  `psw <= take ? V : psw` is the same clocked value as `psw_n = V; psw <= psw_n`.

**AND THE ARGUMENT GETS A FALSIFIER, WRITTEN BESIDE IT** (`ifndef SYNTHESIS`,
in the clocked observer, so it runs once per settled CE clock):

> **`rd_edge_psw_take` |-> `row_blocked && !poste && !iend_owed`.**

If that ever fires, the two forms are not equivalent on that clock, **the pass
is not structural, and it is reverted** — the assertion is the thing that
decides, not the score.  It stays in the tree afterwards as a standing
falsifier.
