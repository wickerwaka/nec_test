## §1 THE CHANGE, AND THE USER DECISION THAT AUTHORISES IT

**The user's decision, 2026-08-04, verbatim: *"Okay, add the output enable."***

§56.3a's intervention needs an "is anyone driving" term.  §58.6 could not write
one and said why: *"a keeper on the net needs an 'is anyone else driving' term
whose only honest source is the core's own output enable, which is not a port,
and manufacturing one in the harness would be re-deriving the core's OE from
its status pins — a fitted rule in the exact place the intervention must not
have one."*  So the offline model asked the NET instead (`core_ad[i] === 1'bz`)
— and §59.7.1 measured what that costs in silicon: **Quartus 17.1 folds
`=== 1'bz` on an internal tri-state to a constant, `core_ad_eff` collapses to
`core_ad`, the hold register loses its fanout and is DELETED at elaboration.**
The fabric leg was blocked and was handed on unrun rather than reported as a
refutation.

**The user's decision removes the premise, not the prohibition.**  The V30's
own pads have an output enable — nothing is being invented, and nothing is
being fitted.  The core now PUBLISHES it:

```
    output [19:0] AD_OE
    assign AD_OE = {{4{ad_oe_addr | ad_oe_ps}}, {16{ad_oe_addr | ad_oe_data}}};
```

The right-hand side is character-for-character the enable term the two
`assign AD[...]` statements already use to decide whether to drive.  It is a
WIRE, not a rule: it adds no logic and cannot disagree with the drive.
§56.3a's prohibition — on the HARNESS manufacturing an OE — **stands and is
satisfied**: the retention model now reads the core's own truth.

**BOTH CORES GET IT.**  The A/B discipline requires the two bitstreams to
differ by the CORE and by nothing else, and the two cores are drop-in
alternatives with the same module name and the same port list.  The ARCHIVED
FSM core therefore receives the same one port and the same one wire, under an
explicit user-authorised exception recorded in
`docs/notes/fsm_core_archive_2026-08-04.md` §6a (date, scope: one output port,
no logic change).

`system_large.sv`'s retention model is re-keyed onto it and the `=== 1'bz`
construct is GONE:

```
    wire [19:0] core_ad_drv = core_ad_oe | {4'b0, {16{c_addrv_q}}};
    ... core_ad_drv[i] ? core_ad[i] : core_ad_hold[i]
    always_ff @(posedge clk) if (core_ad_drv[i]) core_ad_hold[i] <= core_ad[i];
```

The OBSERVATION-PATH deviation from the letter of §56.3a is UNCHANGED and its
rationale stays written beside the code: retention is applied to
`hb_ad_sample`, what `nec_bus` captures, and NOT as a keeper on `core_ad`, so
the core's INPUT is untouched and the intervention does not change the thing it
is asking about.

## §3 THE BEFORE-LEG — **FLASH #5's 146 / 283 STANDS, AND THE ARGUMENT IS EXPLICIT**

§68.2 measured the fabric at **146 / 283** on FLASH #5 and established the
strongest available correspondence: *the failing SET is identical to `tb_sys`
base's, all 137 cells, set equality and not a count match.*  Re-confirmed here
on this tree's freshly captured `tb_sys` base: **`base` failing set == FLASH
#5's fabric failing set, 137 == 137, set equality.**

**A fresh fabric baseline on a FLASH #6-without-retention is NOT taken, and
this is the argument for it:**

1. The **only** RTL difference between FLASH #5's source and this tree's
   non-retention build is `AD_OE` — one output port on each core, driven by an
   expression that already existed.  `git diff 3047c2158d -- hdl/rtl hdl/tb`
   is exactly that plus the retention re-key, which is compiled OUT unless
   `X1_AD_RETENTION` is defined.
2. `gen_ucore_qsf.py --check` is green, so nothing about the build's settings
   moved either.
3. The claim "this port changes no behaviour" is not asserted, it is
   **measured**: the `tb_sys` **base** leg — the same `system_large`
   integration the bitstream is built from, with the retention compiled out —
   produces **283 / 283 byte-identical capture records** against HEAD's.

If any of those three were absent this would be a fresh-baseline sitting.  All
three hold, so **FLASH #5's 146 / 283 is the BEFORE.**  Spending a flash and a
board session to re-measure a number three independent lines of evidence say
cannot have moved would not be discipline; it would be ritual.

*What would retract this*: a fabric result on FLASH #6 in which a cell OUTSIDE
the 119 changes its verdict.  §5's bar (ii) is written to catch exactly that,
and if it fires, the before-leg argument above is what gets re-opened first.
