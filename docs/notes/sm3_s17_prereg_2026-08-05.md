## §2 THE DIAGNOSIS — AND IT IS **NOT H7**

Derived from the retained S16 rows (silicon) and the engine's own rows,
offline. The instrument is `sw/sm3_haltsupp.py` (new, a MEASUREMENT tool,

### §2.1 THE COORDINATE

    arm   the capture row of the CODE T1 at the case's anchor -- the row the
          rig's `ev_st` FSM arms on (`nec_bus.sv` lines 486-527)
    A     the row the pin goes HIGH on = arm + delay + 2 (the rig's own
          documented offset; `sm3_nmigeom.py`'s header derives it)
    H     the row the HALT status appears on.  H is a property of the
          (form, program, wait level) and NOT of the delay: it is
          **8 / 12 / 14 / 16** at w0 / w1 / w2 / w3, on all 18 programs.

### §2.2 THE SILICON LAW — `sm3_haltsupp.py chip`, 1,512 retained captures

A `HLT` whose pin event arrives early enough **never puts a HALT status on the
bus at all**. The part still executes the HALT — the pushed frame is the one
AFTER the `F4`, which is why `emit_evt_case`'s `recognition off-window` guard
composes these cases at all — and the ANNOUNCEMENT is cancelled.

| form | pin | ie | largest `A − arm` that suppresses, w0 / w1 / w2 / w3 | **K = H − that** |
|---|---|---|---|---|
| `HLT.INT` | INT | 1 | 5 · 9 · 11 · 13 | **3** |
| `HLT.RES` | INT | 0 | 5 · 9 · 11 · 13 | **3** |
| `HLT.NMI` | NMI | either | 2 · 6 · 8 · 10 | **6** |

> **THE LAW.** The HALT announcement at clock `H` is cancelled iff the pin
> event's assert clock `A` satisfies **`A <= H − K`**, with **`K = 3` for the
> INT pin and `K = 6` for the NMI pin**.

It is **invariant over the wait level** (4 levels), **over the program**
(6 per form, spanning all three S16 nibble classes), and **over IE**
(`HLT.INT` ie=1 and `HLT.RES` ie=0 share `K = 3`). 126 cells behind every
table entry, **no exception in 1,512**.

## §3 THE CHANGE — TWO CANDIDATES, AND THE ARITHMETIC THAT SEPARATES THEM

`hdl/rtl/ucore/v30u_eu.sv` only, in the F43 wake/display group. **No flop is
added by either candidate**, so `SS_VERSION` / `SS_COUNT` / `SS_TAG` do not
move and `ss_lint` must stay green.

### §3.1 The ucore's present geometry, derived (not fitted)

F43 already writes the rule: *the display for clock `H` is decided at the edge
ending `H−1`, and it is suppressed when the wake decision `D` satisfies
`D <= H`*. The INT half implements it as `int_p[1]` (the pin at `c−2`) read at
`c = H−1`, i.e. `A + 2 <= H − 1`, i.e. `A <= H − 3` — **the measured `K = 3`.**

For NMI the ucore has **no display term at all**: `hlt_wake_disp` carries
`!irq_nmi_lvl`, and the NMI wake rides `unhalt_pend`, which is set in
`S_IRQ_D`. Walk it: with `c0` = the first `S_HALTED` clock on which
`irq_nmi_lvl` (= `nmi_latch`, true from `A+4`) is up, the EU leaves `S_HALTED`
at the end of `c0`, is in `S_OPC_POP` at `c0+1`, `S_IRQ_D` at `c0+2`, and
`unhalt_pend` reads true from `c0+3` = `A+7`. Suppression then needs
`A + 7 <= H − 1`, i.e. **`A <= H − 8` — which is exactly the measured ucore
threshold** (§2.3). The arithmetic is confirmed by the data before anything is
changed.

### §3.2 The two candidates

**V-A — read the latch where the INT level is read.**

```systemverilog
wire hlt_wake_disp = (st == S_HALTED) && (int_p[1] || nmi_latch);
```
`nmi_latch` is true from `A+4`, so at `c = H−1` this gives `A + 4 <= H − 1`,
i.e. **`A <= H − 5`**.

**V-B — the wake DECISION, one clock past it, and it needs no new state.**

```systemverilog
// the NMI wake has been DECIDED and its entry has not yet run
wire hlt_wake_nmi = eu_halted && (st != S_HALTED);
assign eu_unhalt_disp = hlt_wake_disp || unhalt_pend || hlt_wake_nmi;
```
`eu_halted` and `st <= S_HALTED` are written in the SAME arm (`S_DECODE2`), so
the term is false everywhere before the HALT; on the INT wake `eu_halted` is
cleared in the same arm that leaves `S_HALTED`, so it is false there too — it
is **NMI-specific by construction**, not by a pin test. It is true at `c0+1`
and `c0+2`, so at `c = H−1` it gives `A + 5 <= H − 1`, i.e. **`A <= H − 6`**.
