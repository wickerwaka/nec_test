## Case 52/53: aligned maximum-length immediate INS

`fz1081` exposed a one-clock-early memory-write T1 after an aligned immediate
INS with `ie_off=1`, `ie_len=9`.  Sweeping the operand-read wait 0--7 and 15
showed:

- chip write deadline: `read_T1 + 41` for waits 0--7;
- old RTL deadline: `read_T1 + 40`;
- at wait 15, the independent read-completion floor overtakes both deadlines.

The initially nominated `fz1021` control was rejected: its generated byte list
contains the same form, but a patched near branch jumps over it.  Generator
membership is therefore not evidence of execution.

`biu_case52_ins_control_search.py` searched for the exact geometry and then
required the expected IY-address MEMR->MEMW pair in the actual RTL bus trace.
It found 14 executed controls among seeds 0--19999.  `fz3228` independently
reproduced the complete `fz1081` surface at a different reconstructed queue
depth (5 versus 6), under two preparation histories.

The existing one-clock `last_read_tw2` subtraction is consequently excluded
for aligned immediate `off1/len9`; the completion floor is unchanged.

## Case 54: CLI/STI uses physical queue presence

The remaining `fz1068` discrepancy was one PS-pin row: the chip cleared the
interrupt-enable status during a CLI boundary one clock before RTL.  A
chip-versus-FPGA-core run reproduced the first mismatch on the shared physical
capture path, ruling out a Verilator-only sampling artifact.

Sweeping the CODE fetch that supplies the successor bytes isolated only Tw1:

- Tw0: `q_cnt=3`, `q_avl=3`; both commit IE at the CLI pop.
- Tw1: `q_cnt=3`, `q_avl=1`; the chip commits, old RTL defers one clock.
- Tw2: `q_cnt=1` at the CLI pop while the push coincides; both defer.
- Tw3--7 and 15 follow the Tw2 deferred path exactly.

Thus the boundary tests whether another byte is physically queued, not whether
that byte has reached the BIU's delayed pop-maturity counter.  `q_avail2`,
which is consumed only by CLI/STI boundary logic, now derives from
`q_cnt >= 2`.  Both preparation histories match at waits 0--7 and 15,
including the complete QS sequence.
