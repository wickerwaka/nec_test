# ss_flopcensus --core ucore whitelist -- regs the clocked-block rule counts as
# flops that carry NO state across a clock edge.
#
# Format: one entry per line, `signal_name  # justification`.
# The justification (text after #) is MANDATORY; an entry without one FAILS.
#
# WHY THIS FILE EXISTS AND THE FSM ONE IS EMPTY.  The ucore's EU is written in
# the model's software style: blocking `=` throughout.  Its BLOCK-LOCAL WORKING
# VALUES are therefore module-scope `reg`s too, indistinguishable by
# declaration from architectural state.  Every entry below is one of those: on
# every clock it is WRITTEN BEFORE IT IS READ, by a write that dominates every
# read of it, so no value survives the edge and there is nothing for a
# save-state to carry.  Each was checked by hand against its write sites and its
# read sites (U3 platform audit).
#
# TWENTY-TWO OF THE TWENTY-FOUR ENTRIES ARE GONE, AND NOT BY HAND (U4 pass 3).
# The U3 audit booked this file as "A WORKAROUND FOR A DECLARATION, NOT A DESIGN
# DECISION -- SystemVerilog lets these be declared INSIDE the always block,
# which would remove them from the census by construction", and left it because
# the RTL was frozen.  The ENABLE-FORM refactor did the equivalent as a side
# effect: the EU's body is an `always @*` next-state function now, so `stop`,
# `ie_now`, `v1`, `v2`, `bsw`, `pv`, `nloc`, `carry`, `taken`, `bubble`,
# `retire_now`, `rep_chained`, `ea`, `rseg`, `rmmod`, `rmreg`, `rmrm`, `tk`,
# `ti`, `te`, `ts` and `tb` are COMBINATIONAL by declaration and the census
# classifies them without being told.  The EU's architectural-flop count falls
# 140 -> 118 and the whole census 223 -> 201 for that reason and no other; the
# MAP is untouched (SS_COUNT 218, SS_TAG 0x82DA, 0 UNMAPPED).
#
# The two that remain are real flops -- they are committed by the register bank
# -- and are whitelisted on their old, unchanged justifications.
#
# Do NOT add an entry here to silence a genuine save-state gap.  A reg that
# carries live machine state across a clock edge MUST be mapped.
